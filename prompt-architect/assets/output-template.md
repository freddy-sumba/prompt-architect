# Formato de entrega

Entrega siempre estas secciones, en este orden:

## 1. Prompt final
```text
[prompt copiable listo para usar]
```

## 2. Supuestos
- [Supuestos hechos por falta de información; "Ninguno" si no hubo]

## 3. Variables a completar
- `{{variable}}`: [qué debe ir aquí] (omitir si no hay variables)

## 4. Casos de prueba
1. [Caso típico] → [resultado esperado]
2. [Caso límite] → [resultado esperado]

## 5. Cambios (solo si se mejoró un prompt existente)
- [Qué se cambió y por qué]
